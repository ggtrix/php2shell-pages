A critical flaw in PHP itself. Is it on your external attack surface?

On October 21, PHP released emergency patches for PHP2Shell, two critical vulnerabilities that allow unauthenticated remote code execution on any PHP installation serving web requests. Exploitation attempts were seen in the wild before the fix was public.

Because the flaws sit in the PHP runtime, even fully patched WordPress, Drupal, Laravel or custom applications stay exposed if the PHP underneath is vulnerable.
