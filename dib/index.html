// Defense Industrial Base & DoD contractors

CVE-2026-109618 CVE-2026-109619 CVSS 9.2 · Pre-auth RCE

One unpatched PHP server. A security gap, a compliance finding and a DoD contract at risk.

PHP2Shell is a critical, unauthenticated remote code execution vulnerability in the PHP core that can be triggered before any application code runs. Partner portals, bid platforms, contractor websites and internal tools exposed to the internet are at immediate risk if they run an unpatched version.

Because the flaw is in the PHP runtime itself, fully updated applications stay vulnerable until PHP is updated to 8.2.35, 8.3.36, 8.4.27 or 8.5.12, or a verified vendor equivalent, and workers are restarted. Exploitation attempts were observed in the wild before the October 21 patches.

// Exposure & compliance impact

A security gap. A compliance finding. A contract at risk.

For DIB contractors, an unpatched instance creates potential compliance implications under CMMC and NIST SP 800-171, particularly around vulnerability management, system integrity and protection of Controlled Unclassified Information (CUI). Left unremediated, it can put your current and future Department of Defense contracts at risk.
